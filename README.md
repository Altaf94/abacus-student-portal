# Abacus Student Portal

React front-end for students on the abacus learning platform.

## Context

Uses the Abacus Learning API (Django REST Framework).

## Features

- Authentication pages
- Student pages built with React Query, React Hook Form and Zod validation

## Tech stack

- **Frontend:** React, Tailwind CSS, React Query, React Hook Form, Zod, axios

## Getting started

```bash
yarn install
yarn start
```
